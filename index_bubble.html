COVID-19 Bubble Chart: Cases, Deaths & Mortality Rate

Bubble size = Mortality Rate | Countries above diagonal had worse outcomes
📊 How to Read This Chart:
X-axis: Total number of COVID cases (logarithmic scale)
Y-axis: Total number of deaths (logarithmic scale)
Bubble size: Larger = higher mortality rate
Color: Red = high mortality, Green = low mortality
💡 Interactive Features:
• Hover over any bubble to see detailed country statistics
• Zoom in/out using mouse wheel or trackpad
• Drag to pan around the chart
• Double-click to reset zoom
